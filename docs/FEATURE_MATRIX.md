# Feature Matrix

Statuses use the requested vocabulary: **Verified**, **Implemented-Unverified**, **Partial**, **Simulated**, **Unavailable**, or **Blocked**. Verified means the specific behavior was executed and observed locally; it does not imply production or live-service validation.

| Feature | UI component | API endpoint | Service/data | Tests observed | Status | Notes |

| Role dashboards and navigation | `App.tsx`, four role dashboards | Multiple dashboard APIs | React local state | Client build passes | Verified | UI renders from state; there is no URL router or role-specific authorization proof from rendering alone. |
